# @ziuus/vanta has moved to Orbit!

> **Notice:** Vanta has been rebranded and rewritten as **[Orbit](https://github.com/ziuus/orbit-tui)** (`@ziuus/orbit` on npm).

## How to Migrate:

```bash
# 1. Remove old vanta
npm uninstall -g @ziuus/vanta

# 2. Install orbit
npm install -g @ziuus/orbit
```

Or build from source via Cargo:
```bash
cargo install --git https://github.com/ziuus/orbit-tui
```
